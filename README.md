# 🎬 Streaming Platform UI

A modern streaming platform web application built with **React.js**, featuring user authentication, responsive design, and a clean user interface.

This project marks the **first milestone** of my DevSecOps learning journey, where I aim to build, secure, and deploy a production-style application using industry-standard tools and best practices.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/streaming-platform-react.git
```

### Navigate to the project

```bash
cd streaming-platform-react
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm start
```

The application will be available at:

```
http://localhost:3000
```
